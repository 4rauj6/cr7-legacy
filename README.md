### What are the main goals of this project?
**1. Honor CR7's career.**
   - Cristiano's football career is one of the most succesfull carreers in the football world. To celebrate that, the CR7 Legacy project started to be developed.
     
**2. Connect with other Cristiano Ronaldo's fans**
- As one of the most famous football athlete in the world, Cristiano has a lot of fans worldwide. To connect all of them, that want to know more about their idol, CR7 Legacy are here.

**3. What problem this project solve?**
- 1. To improve the author's skills with Front-End (Web, Mobile, React and Tailwind) development.
- 2. To create something new that can help someone.
